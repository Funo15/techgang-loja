🛒 TechGang — AliExpress Importer

Arrasta o botão abaixo para a tua barra de favoritos:

⬇️ Importar para TechGang
Como usar:
  1. Arrasta o botão roxo para a barra de favoritos do browser
  2. Abre qualquer produto no AliExpress
  3. Clica no favorito "Importar para TechGang"
  4. Abre uma página no teu admin com tudo pré-preenchido
  5. Ajusta o preço de venda e clica "Importar"
⚠️ Tens de estar autenticado no admin do TechGang (techgang.pt/funitocorp) para o import funcionar.
