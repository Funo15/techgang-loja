A TechGang Lda é responsável pelo tratamento dos dados pessoais recolhidos através de techgang.pt, nos termos do Regulamento Geral sobre a Proteção de Dados (RGPD — Regulamento UE 2016/679).

2. Dados que recolhemos e finalidade

Recolhemos apenas os dados estritamente necessários para as seguintes finalidades:

  • Processamento de encomendas: nome, email, telefone, morada de entrega — base jurídica: execução de contrato (art. 6.º, n.º 1, al. b) do RGPD).
  • Comunicações transacionais: envio de email de confirmação de encomenda e informação de rastreio — base jurídica: execução de contrato.
  • Conta de cliente: email e password (armazenada de forma encriptada) — base jurídica: execução de contrato.
  • Cumprimento de obrigações legais: dados de faturação conservados pelo prazo legal de 10 anos — base jurídica: obrigação legal (art. 6.º, n.º 1, al. c) do RGPD).
  • Cookies de marketing (Pixels): se o utilizador consentir, recolhemos dados de navegação para fins publicitários através de Meta Pixel e/ou TikTok Pixel — base jurídica: consentimento (art. 6.º, n.º 1, al. a) do RGPD). O consentimento pode ser retirado a qualquer momento.

3. Partilha de dados com terceiros

Os teus dados pessoais podem ser partilhados com:

  • Fornecedores (dropshipping): nome e morada de entrega, necessários para o envio do artigo.
  • Stripe: processamento seguro de pagamentos. A Stripe é responsável pelos dados de cartão — consulta a política de privacidade em stripe.com/pt/privacy.
  • Serviços de rastreio (17track): número de encomenda e email, para notificações de envio.
  • Railway (alojamento): infraestrutura técnica onde os dados são processados — servidores na UE/EEE.

Não vendemos, alugamos nem cedemos dados pessoais a terceiros para fins comerciais.

4. Cookies

Utilizamos os seguintes tipos de cookies:

  • Cookies essenciais: necessários para o funcionamento da loja (sessão de cliente, carrinho). Não requerem consentimento.
  • Cookies de marketing: Meta Pixel e TikTok Pixel, utilizados para medição de campanhas publicitárias. Só são ativados após consentimento expresso.

Podes gerir as tuas preferências de cookies a qualquer momento através do banner de cookies ou contactando-nos por email.

5. Os teus direitos (RGPD)

Enquanto titular de dados, tens os seguintes direitos:

  • Direito de acesso: saber quais os dados que temos sobre ti.
  • Direito de retificação: corrigir dados inexatos ou incompletos.
  • Direito ao apagamento: pedir a eliminação dos teus dados (salvo obrigações legais de conservação).
  • Direito de oposição: opor-te ao tratamento para fins de marketing.
  • Direito de portabilidade: receber os teus dados num formato estruturado e legível por máquina.
  • Direito de retirar o consentimento: a qualquer momento, sem prejuízo do tratamento anterior.

Para exercer qualquer destes direitos, contacta-nos em {{EMAIL}}. Tens ainda o direito de apresentar reclamação à autoridade de controlo competente: CNPD — Comissão Nacional de Proteção de Dados.

6. Conservação dos dados

Os dados de encomenda são conservados pelo período mínimo legalmente exigido (10 anos para efeitos fiscais). Os dados de conta de cliente são eliminados mediante pedido, desde que não existam obrigações legais de conservação em curso. Os dados de marketing (pixels) não são conservados pela TechGang Lda — ficam na posse da Meta/TikTok de acordo com as suas políticas.

7. Segurança

Adotamos medidas técnicas e organizativas adequadas para proteger os teus dados contra acesso não autorizado, perda ou destruição, incluindo encriptação de passwords, comunicações HTTPS e acesso restrito à base de dados.
